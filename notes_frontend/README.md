# Ocean Notes – Simple Notes Frontend

A modern, lightweight React notes app with an Ocean Professional theme. Supports creating, viewing, editing, and deleting notes with localStorage persistence.

## Features
- Create, edit, and delete notes
- Instant updates and automatic saving
- LocalStorage persistence
- Responsive two‑panel layout (sidebar list + editor)
- Ocean Professional styling (blue & amber accents), rounded corners, subtle shadows, smooth transitions
- Seed sample notes on first load

## Run locally
- npm start
- Open http://localhost:3000

No backend or environment variables required.
